# Public test evidence

editor5-summary.json is a sanitized summary of actual local tests, not a raw diagnostic or complete engine snapshot. Private diagnostics, scenarios, launcher identities and research data are not published.

The three screenshots were freshly captured and their saved images visually checked before publication: grouped setup at requested1200×900, Ranged with721 results, and the genuine native Abyssal Shellback card with sprite and70/70 HP. CrabCult was active in the isolated profile. These images do not repeat the earlier fights. Older ambiguously named images were excluded; earlier workflows were observed live and their numerical results independently checked from native exports.

- [Ranged: 721 results](menu-mods-2026-11-14/visible-ranged-721-results.png)
- [Native Abyssal Shellback card](menu-mods-2026-11-14/visible-mod-native-inspect.png)

These are historical editor.5 images, not screenshots of every later development build. Publication changed version/description text, documentation and packaging, not the then-tested runtime. The required separate experimental Extender is not bundled; stock upstream does not already meet the complete editor dependency.

Screenshots depict Illwinter's Conquest of Elysium5 and some CrabCult content. Rights to those graphics remain with their authors. No standalone game sprites/assets or CrabCult files are distributed. The MIT license of this project's own code grants no rights to third-party artwork.

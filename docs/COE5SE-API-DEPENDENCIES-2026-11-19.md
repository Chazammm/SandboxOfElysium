## Where to find the tested reference work

The older local reference is separate from these PRs. Its 3.4.4-era source uses `test_field_lifecycle.h` and `lua_test_field_editor.h` for native scope and setup, `lua_test_field_release.h` for context and actor state, and `lua_test_field_deployment.h` with `lua_test_field_initial_deployment.h` for exact reconstruction. Naming and type preview are in `lua_test_field_names.h` and `lua_test_field_monster_inspect.h`. Presentation is in `lua_test_field_zoom.h`, `lua_test_field_log.h` and the fitted sprite helpers in `lua_ui.h`. See the [earlier reference pairing](TEST-RELEASE-CANDIDATE-2026-11-19.md). Its visible tests are historical evidence for that pairing.

## Dependency order

1. Retirement and minimum width can be reviewed independently. Naming builds on owned identity and retirement.
2. Stock native contexts and exact restoration share the field generation and structure provenance contract. Review together with bounded condition and spell restoration. Final provenance builds on this classification.
3. Live unique policy, log visibility and transactional held-item clearing follow the core integration. Review `48a6687` with the log capability from `955f7af`, and `26512a3` as an equipment transaction.
4. Review viewport and camera at `review/owned-field-viewport-20261119` (`26af902`). Its callback uses the owned field's drive and cleanup paths and existing projection.
5. Review genuine type View at `review/owned-field-presentation-20261119` (`a372833`). It builds on the viewport change to preserve a fitted and panned editor view as part of card cleanup. Its unique check uses the owner's native constructor path.

The stock upstream comparison preserved the setup while refusing Guard Tower, saved personal names and the explicit width. The editor startup gate still blocks stock dev. The separately built Windows review stack is ready for local candidate review. Public release requires integration into an official compatible CoE5SE build and verification of that build. See [the combined-build test report](TEST-COMBINED-PRESENTATION-2026-11-19.md) for coverage and limits.

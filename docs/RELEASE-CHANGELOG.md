# Changelog

## 0.2.0-beta.2

- Verified with official CoE5SE 3.8.2 on Windows CoE5 5.43.
- Added an opt-in Ctrl + right-click and drag deletion tool for placed army units. Enable it in the battlefield footer.
- Reopen Sandbox after changing enabled mods to refresh the unit browser and portraits. In-memory setups stay with their original mod list, and saved scenarios keep their existing requirements.

## 0.2.0-beta.1

First public beta of Sandbox of Elysium for Windows CoE5 5.43 x64 and official CoE5SE 3.8.1.

- Create two armies on 21 supported battlefields, from land and siege maps to independent-unit sea and coastal battles.
- Search and filter the roster, preview a unit in its native card, deploy single units or formations, and configure supported equipment, magic and names.
- Place and inspect supported Neutral walls, parapets and stairs. Keep native siege gates and army counts separate.
- Use native zoom, pan, Fit and combat-log controls. Run battles with the native AI and view the supported aftermath.
- Save and restore setups, Reset or Rematch, and export diagnostics when a native operation is refused.
- Recover exact supported stock implant layouts and injury state even when a recreated unit starts with a different implant or none.

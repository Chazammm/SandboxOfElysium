# Sandbox of Elysium 0.2.0-beta.2

Build two armies, set up a battlefield and watch the native Conquest of Elysium 5 AI fight. Open **Sandbox** from the main menu to start a standalone battle.

**Requirements:** Windows x64 Conquest of Elysium 5 version **5.43** and the separately installed official **CoE5SE 3.8.2**. [Install and update](INSTALLATION.md) · [Official CoE5SE 3.8.2](https://github.com/musical-pianist/coe5se/releases/tag/CoE5SE-v3.8.2)

- Choose from 21 supported land, siege and water or coastal battlefields. Set a minimum field size, use formations, and adjust the native view with zoom, pan and Fit.
- Search and filter vanilla and loaded mod content. Open the native unit card with **View** before placement. Edit eligible equipment, existing magic schools, spells and individual names.
- Place Neutral walls, parapets and stairs on supported land and siege maps. Inspect verified scenery and native gates with their own game cards.
- Save a setup, fight, then use **Back to Sandbox**, **Reset** or **Rematch** to rebuild the pre-battle layout and supported unit state.
